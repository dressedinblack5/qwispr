# Benchmarks

## Suites

- **Synthetic** — generated QUBOs (n=3..5), deterministic, fast. `npm run benchmark` → `results/synthetic.json`
- **Real** — derived from repo call-graphs / QUBOs. `npm run benchmark:real` → `results/real.json`
- **Report** — comparison table + summary. `npm run benchmark:report` → `report/index.md` + `report/data.json`

```bash
BENCH_N=2 npm run benchmark        # limit cases (ponytail: BENCH_N)
npm run benchmark:real
npm run benchmark:report
cat report/data.json
```

## Lightning note

`lightning.qubit` is ~5–10× faster than `default.qubit` for VQE/QAOA when `pennylane-lightning` is installed. Set `QWISPR_BACKEND=lightning` or `QWISPR_DEVICE=lightning.qubit`. Falls back to `default.qubit` if the plugin is missing — no code change needed. See `src/skills/hardware/backend.ts` and `src/skills/qaoa-agent/qaoa.py:get_device()`.
